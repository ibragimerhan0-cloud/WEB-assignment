# Aura Coffee Roasters — Assignment 3

Responsive four-page coffee shop website created with HTML5, CSS3 and Bootstrap 5.3.3.

## Team

- Shalabay Madi — SE-2510
- Yerkhan Ibragim — SE-2510

## Pages

- `index.html` — Home page
- `menu.html` — Menu, Bootstrap cards, buttons and 9-image carousel
- `about.html` — Story and team information
- `contact.html` — Responsive Bootstrap contact form

## Assignment features

- Responsive typography with CSS media queries
- CSS-only responsive card group: 1, 2 and 3 columns
- Bootstrap 12-column grid
- Bootstrap spacing utilities
- Responsive Bootstrap navbar with four links
- Primary, secondary, outline, large and small buttons
- Button group
- Bootstrap carousel with nine different images
- Three Bootstrap cards
- Form controls, input group, radio buttons and checkbox
- Semantic HTML, labels, alt text and ARIA attributes

## Run locally

Open `index.html` in a browser or use the Live Server extension in VS Code.
